# 🚑 AETA – Advanced Emergency Traffic Aid

A responsive website created to present **AETA (Advanced Emergency Traffic Aid)**, an innovative project developed for the **International Science and Engineering Fair (ISEF)**.

The website explains the project's problem, objectives, proposed solution, and expected impact through a modern and responsive interface.

## 📖 About the Project

AETA is designed to improve emergency response by reducing delays caused by heavy traffic. The project focuses on supporting ambulances and emergency vehicles through intelligent traffic management, helping save lives while reducing congestion and environmental pollution.
